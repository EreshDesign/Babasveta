# Баба Света

Сайт для автора интерьерных матрёшек.

## О проекте

Концептуальный сайт для мастера, создающего авторские матрёшки для современного интерьера.

Проект разработан как personal / educational project: от визуальной концепции и UI-дизайна до адаптивной вёрстки и публикации сайта.
